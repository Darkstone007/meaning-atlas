Make an ID first

A guest cannot add a word. Make an ID. For now the passphrase is that user ID. You can log in with the user ID and that passphrase, unless you change the passphrase. The ID is not shown on the main page.

Add what it means to you

The word, the language, the meaning, an example, and what it carries are required. There won't be any changes to your meaning or text and it will be displayed as written. On the other hand a label is separate, it is the name a dashed line can use. Pick at least one label for emotion, one for context, and one for intention.

Picture, voice, or video, if you want

Each file has a maximum of 1.5 MB. JPEG, PNG, WebP or GIF for a picture. MP3, WAV or OGG for a voice. MP4 or WebM for a video. A file over that size stays off the account and the rest of what you wrote is kept. Send the file to the owner if you want it included. An unlisted YouTube link can be pasted for playback. Unlisted is not private: anyone with the link can open it. Leave a slot empty and nothing blank is shown.
